# Board Game Agent

Multi-agent CLI advisor for board games (player-perspective). Uses DeepSeek API.

## Setup

```bash
pip install -e ".[dev]"
cp .env.example .env
# put your DEEPSEEK_API_KEY in .env
```

## Run

```bash
python -m board_game_agent --help
# or: bga --help
```

Session commands and agents are implemented in subsequent tasks.
